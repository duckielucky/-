# Lucky Scratch

Lucky Scratch is a dark-purple lottery scratch-card game built with Vinext and designed for deployment on Cloudflare Workers.

## Features

- User login and registration
- Interactive scratch-card game
- Normal Win, Big Prize, and Jackpot effects
- Player profile page
- Manager dashboard
- Responsive mobile and desktop design
- Browser-based game progress storage

## Requirements

- Node.js `>=22.13.0`
- npm
- Cloudflare Workers account
